FOTO (taruh di folder ini; kalau belum ada otomatis tampil blok warna):
{program}-cover.jpg -> foto lebar pembuka tiap program. Contoh: 1-cover.jpg = Syiar ID
{program}-{momen}.jpg -> foto 3 momen cerita. Contoh: 1-1.jpg, 1-2.jpg, 1-3.jpg
Urutan program: 1 Syiar ID, 2 Syiar Melingkar, 3 Kajian Strategis, 4 Sapa Syiar, 5 SMF, 6 Unsri SJP
bph-1.jpg, bph-2.jpg, bph-3.jpg -> foto BPH

CERITA, NAMA, BPH, ANGGOTA: buka js/main.js, edit bagian "ISI CERITA" di atas.
Tiap program: nama singkat, judul, warna, subjudul, kalimat pembuka, kutipan, dan 3 momen (label, judul, cerita).
Teks program saat ini hanya contoh umum, silakan diganti dengan cerita sebenarnya.
GERBANG PEMBUKA: di js/main.js ada AUTO_BUKA. 0 = harus diklik; isi 4 untuk terbuka sendiri setelah 4 detik.
